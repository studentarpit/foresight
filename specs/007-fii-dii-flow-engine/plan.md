# Implementation Plan: FII/DII Flow Intelligence Engine

**Branch**: `007-fii-dii-flow-engine` | **Date**: 2026-05-26 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/007-fii-dii-flow-engine/spec.md`

## Summary

Add FII/DII institutional flow intelligence to Foresight without modifying any existing features. The engine tracks who is buying/selling each stock, how long that pattern has run, and what it historically meant for price. It surfaces a Flow Score (0–100 or N/A) per stock and six new UI components across the Discover, Analyse, and Sentiment tabs. All data sources are free (NSE API, screener.in); Claude API is used optionally for historical pattern insight.

## Technical Context

**Language/Version**: Python 3.10+

**Primary Dependencies**: requests, BeautifulSoup4 (HTML parsing), concurrent.futures (stdlib, parallel fetch), anthropic SDK (AI insight, optional), streamlit, plotly, pandas

**Storage**: TTL JSON file cache in `cache/` directory — same pattern as all other Foresight data fetchers

**Testing**: No formal test suite (project convention); imports verified with `python -c "from ... import ..."` after each file

**Target Platform**: Windows 11 / Streamlit desktop web app (single user)

**Project Type**: Streamlit dashboard add-on feature — purely additive, no existing code modified

**Performance Goals**:
- Shareholding batch prefetch for 20 stocks: < 5s (parallel 4 workers, 0.5s stagger)
- Flow heatmap render: < 2s (all scores from cache)
- FII/DII daily strip: < 1s (1h TTL cache; NSE cookie session on first load ~1.2s)

**Constraints**:
- screener.in rate limit: 0.5s stagger between parallel thread starts
- NSE API: requires cookie session (GET homepage → wait 1.2s → GET data endpoint)
- Do NOT modify FVS Score calculation — Flow Score is a parallel metric only
- All functions must be cache-first; never raise exceptions to caller

**Scale/Scope**: 20–80 stocks per scan; single-user desktop app; no concurrent users
