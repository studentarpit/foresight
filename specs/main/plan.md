# Implementation Plan: Foresight

**Branch**: `main` | **Date**: 2026-05-22 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/main/spec.md`

## Summary

Build a 4-tab Streamlit dashboard that scans a curated universe of ~50 Indian stocks and ~100
mutual funds, applies a financial filter, sends passing companies to Claude for AI conviction
scoring, and surfaces ranked results with valuation modeling and thesis tracking.

## Technical Context

**Language/Version**: Python 3.10+

**Primary Dependencies**: streamlit, yfinance, pdfplumber, requests, beautifulsoup4, anthropic, pandas, python-dotenv, plotly

**Storage**: In-memory DataFrames + `data/tracker.json` for Master Tracker persistence

**Testing**: Manual smoke test via `streamlit run main.py`

**Target Platform**: Local desktop (single-user)

**Project Type**: Data dashboard / Streamlit web app

**Performance Goals**: Full scan < 90s for 25 companies; valuation model < 10s

**Constraints**: No paid APIs; graceful degradation when scraping fails; functions < 50 lines

**Scale/Scope**: ~50 stocks + ~100 MFs, single user, MVP
